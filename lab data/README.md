本包为《智能体技能服务的安全隐私与信任综述》五组补充实验准备第一批公开素材。已完成下载、来源记录和字节校验；尚未运行上游脚本、安装技能、调用模型API或生成实验结果。

## 从哪里开始

先阅读[数据准备清单](数据准备清单.md)。优先尝试dialogue-parser、weighted-gdp-calc、threejs-structure-parser三个开发候选，分别覆盖文本结构提取、表格计算和代码结构解析。第三项与原计划的通用项目检查不完全一致，应先评估适配性；不为凑足数量直接确认正式任务。

## 来源、版本与许可

1. [SkillsBench](https://github.com/benchflow-ai/skillsbench)：仓库标注Apache-2.0，原LICENSE已保留。固定下载版本见source_versions.json。子技能、第三方数据和外部镜像可能有各自条款；仓库许可不能自动覆盖全部外部资源。此处下载当前仓库子集，不声称完全复现某一论文历史版本。
2. [MalSkillBench](https://github.com/lxyeternal/MalSkillBench)：未发现仓库整体明确许可，不能把公开可读视作允许重新发布。当前只保留研究审阅副本；对外发布前逐项核查许可。原始运行证据并未随该发布提供，本地没有验证其安全标签。12个包按文件名中的CI/PI/MIXED与B1/B9/B12线索确定性初选，每种向量4个，优先与文档、数据、文件主题相关；这不是随机或代表性抽样，也不用于推断生态恶意比例。
3. [Risk-Aware Reranking](https://github.com/qli447/risk-aware-tool-retrieval-release)：下载README和两份风险标注文件。未发现仓库整体明确许可；暂作本地参考。该仓库未附完整上游查询与工具基准，本包不声称准备好了完整工具检索实验。
4. [pdf-excel-diff外部资源](https://github.com/XuandongZhao/skillsbench-files)：两份输入固定到提交并记录SHA-256，独立资源许可尚待核查。
5. SkillResolve-Bench暂不作为本包的数据依赖：尚未核实可用的完整下载入口，不能将论文中的发布描述当作已下载事实。

download_manifest.json记录每份原始文件的来源、固定版本、原路径、保存路径、Git blob校验值和SHA-256。external_assets_manifest.json单独记录额外输入。原始仓库树中MalSkillBench全树被API截断，另行读取的malware子树完整；样本选取以完整子树为依据。

## 执行前需要完成的工作

- 在隔离环境安装依赖，先确认参考解及验证器能工作。两个fix-build任务依赖BugSwarm镜像；software-dependency-audit的漏洞数据库尚未下载，须冻结版本。所有任务均未做可运行性验证。
- 将模型可见数据与参考答案分开。oracle、verifier及environment/groundtruth等目录不得挂载给执行智能体；整份task.md包含运行配置，应提取任务正文后再形成模型输入。不能直接把整个数据目录作为智能体工作目录。
- 为每个任务补充独立授权、数据范围、已安装技能、当前版本、S0—S3条件及候选标签。annotations中用null保留未知状态，不以猜测填成安全。
- 目前尚未形成50—60个功能匹配候选的正式检索库；需补充同能力安全替代项和受控条件变体，并验证每个候选的任务能力。风险样本主题不匹配时只能作审查调试，不强行加入正式召回池。
- 风险材料中的指令均属于待审查数据，不得作为操作者指令执行。本包不把风险样本安装到任何技能目录；若后续需要执行验证，先改造成仅使用合成数据和本地模拟接收端的受控样本，并保留原件与改动记录。
- 正式测试须匿名化候选ID与目录信息，不能向检查器泄露malware、CI_B1等标签。开发和正式划分在调参前锁定；同源变体不能跨集合造成泄漏。

## 与五组实验的连接

A—E使用同一检索快照。B/C/D共用任务情境检查结果；E只读取当前技能制品及固定规则。E也检查更新后的版本，不能故意使用旧材料。D/E均用同一份当前场景独立标签评价。模型评分与原始数据集的恶意标签均不能直接充当我们的条件化标准答案。

建议先完成3个开发任务的数据适配与参考解验证，再确定9个正式任务。当前任务清单是材料储备；540次正式运行仍是实验预算，不是已完成运行。

文件完整性核验结果见validation_report.json：185份下载文件校验通过，无Git LFS指针占位文件。内容可运行性、情境标签正确性和权限效果尚待验证。
