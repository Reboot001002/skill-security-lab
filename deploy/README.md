# 服务器部署前检查

完整实验入口和服务器克隆流程见仓库根目录 README.md。此目录保存环境检查与初始化脚本。

把 `server_probe.py` 传到容器后，在计划存放实验的目录运行：

```sh
python3 server_probe.py --target .
```

脚本仅检查系统、Python、磁盘、GPU、容器资源限制和隔离工具是否存在。
不会安装软件、启动服务、访问模型，也不会输出环境变量或凭证。

使用 GitHub 克隆部署时需要确认：

1. GitHub仓库已经克隆到平台的持久化目录。
2. 本地模型服务的接口地址和模型名称；密钥在服务器本地配置。
3. doctor隔离检查通过后再启用真实模型执行。

工具存在不代表隔离可用；必须验证候选进程无法访问模型密钥、标准答案、外部网络和其他运行目录。
检查进程与执行进程应分开；模型调用由隔离边界外的控制程序处理。
先通过单任务开发验证，再扩展开发集与正式集，不自动启动540次正式运行。
